เว็บไซต์พอร์ตโฟลิโอส่วนตัวของ นายรัชพล สุขโต (อายุ 20 ปี)

## หน้าหลัก
- `index.html` — หน้าพอร์ตโฟลิโอแบบ Single Page Application
  - Hero Section (ต้อนรับ + รูปโปรไฟล์)
  - About Section (เกี่ยวกับฉัน)
  - Skills Section (ทักษะและความเชี่ยวชาญ)
  - Contact Section (ติดต่องานผ่านอีเมล)
  - Navigation แบบ Fixed sidebar พร้อม Smooth Scroll

## เทคโนโลยีที่ใช้
- [Tailwind CSS](https://tailwindcss.com/) — CSS Framework สำหรับดีไซน์ทันสมัย
- [GSAP](https://gsap.com/) — Animation Library สำหรับ Scroll Reveal และ Hero Entrance
- [Kanit Font](https://fonts.google.com/specimen/Kanit) — ฟอนต์ภาษาไทยร่วมสมัย

## วิธีการใช้งาน
1. Clone repository นี้
2. เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ (Chrome, Edge, Firefox, ฯลฯ)
3. หรือใช้ Live Server extension ใน VS Code ก็ได้เช่นกัน

## ฟีเจอร์เด่น
- Dark Mode พร้อม Glassmorphism
- Responsive Design รองรับมือถือและแท็บเล็ต
- Animation เข้าเว็บครั้งแรก (Hero Entrance)
- Scroll Reveal Animation ตอนเลื่อนลงดูเนื้อหา
- Background Blobs เคลื่อนไหวอย่างนุ่มนวล
